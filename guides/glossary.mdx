| Word | What it means |
| --- | --- |
| **3D printer** | A machine that makes a solid object by laying down thin lines of melted plastic, one layer on top of another. |
| **Model** | The design of the thing you want to make. EasyPrint shows it on screen before you print. |
| **Library** | The collection of ready-made models your support person has chosen for you. |
| **Filament** | The plastic the printer uses. It comes as a long thin string wound on a reel (a **spool**). |
| **Colour** | Each colour is a different spool of filament. You can only choose colours your support person has made available. |
| **PLA** | The most common type of plastic for 3D printing. It is easy to print and safe to handle. Others you may see: PLA+, PLA Matte, PLA Silk, PETG. |
| **Nozzle** | The hot tip that melts the plastic and draws each layer. **Very hot – do not touch.** |
| **Bed** / **build plate** / **plate** | The flat surface the model is printed on. It gets warm while printing. |
| **Layer** | One thin slice of the model. The printer builds the model one layer at a time, from the bottom up. EasyPrint shows which layer it is on. |
| **Getting your model ready** (slicing) | EasyPrint turns your model into step-by-step instructions the printer understands. This takes a few seconds to a few minutes. |
| **Supports** | Thin scaffolding the printer adds under parts that would otherwise hang in the air. You snap them off afterwards. |
| **Brim** | A thin flat rim printed around the bottom of a model to help it stick to the plate. You peel it off afterwards. |
| **Quality** | How fine the layers are. **Fine detail** looks smoother but takes longer. **Quick** is faster but rougher. **Normal** is in between. |
| **Size** | **Small**, **Normal** or **Large**. Normal is the size the model was designed at. |
| **Approval** | Your support person checking a print before it starts. |
| **Bed is clear** | Nothing left on the plate from a previous print. EasyPrint asks you to check this. |
| **STL** / **3MF** | Types of 3D model files. You can upload these if you have them. |
| **Upload** | Putting a file from the computer into EasyPrint. |
| **Pause** | Stop for now, and carry on later from the same place. |
| **Stop** | Stop for good. The model will not be finished. |
| **Support person** | The person who set up EasyPrint for you and can help if something goes wrong. |
